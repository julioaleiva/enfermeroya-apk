# EnfermeroYa para Android

Repositorio de distribución de las tres aplicaciones Android de EnfermeroYa, desarrollado por WSS W Systems And Solutions.

## Versión disponible

Actualizada el 14/10/2026 con los APK compilados el 13/10/2026. Versión de las aplicaciones: 0.1.0 (código de versión 1).

Los APK se distribuyen como archivos adjuntos de GitHub Releases y no se incluyen en el historial de la rama principal.

- [Administración — enfermeroya-admin.apk](https://github.com/julioaleiva/enfermeroya-apk/releases/latest/download/enfermeroya-admin.apk)

## Instalación

1. Descargá el APK de la aplicación que necesitás en tu dispositivo Android.
2. Abrí el archivo y, si Android lo solicita, permití instalar aplicaciones desde esa fuente.
3. Completá la instalación y abrí EnfermeroYa.

Requieren Android 6.0 o posterior e incluyen soporte para arm64-v8a, armeabi-v7a, x86 y x86_64. Cada APK incluye el código de la aplicación y no necesita un servidor Metro. Las funciones conectadas requieren acceso a Internet.

Estos paquetes usan firma de pruebas de Expo para instalación directa; no son paquetes firmados para publicación en Google Play. Se verificaron la firma, la identidad de cada aplicación y la presencia del código incluido. No se probaron en un teléfono físico.

Si Android rechaza una actualización por incompatibilidad de firma, la versión instalada y este APK tienen firmas distintas. Antes de desinstalar, asegurate de conservar los datos locales que necesites.
